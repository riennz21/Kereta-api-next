Bertindaklah sebagai Senior Frontend Engineer (Next.js & Tailwind CSS) yang ahli dalam UI/UX design. Tugasmu adalah merombak halaman utama (/) dari aplikasi reservasi tiket kereta bernama "TiketKAI". Ubah orientasi desain dari "dashboard monitoring internal" menjadi "platform pemesanan tiket B2C" yang estetik, modern, dan bergaya glassmorphism/clean minimalist.1. Struktur Layout Utama (Halaman /)Header/Navbar: >     * Kiri: Logo "TiketKAI" dengan subtitle "Reservasi Kereta Digital".Kanan (Navigasi Baru): Tambahkan menu Cek Pesanan, Bantuan, dan komponen Profil Pengguna (berupa avatar bundar sederhana dengan nama user yang memiliki dropdown menu: "Akun Saya" dan "Logout").Hero Section:Latar belakang gradasi krem ke putih (seperti style bawaan saat ini).Teks sapaan dinamis (misal: "Halo, Sena! Mau pergi ke mana hari ini?").Main Booking Card (Tabbed Style): Buat satu card putih melayang dengan shadow tipis di tengah atas halaman. Card ini memiliki 2 tab:Tab 1: Pesan Tiket (Aktif secara default)Tab 2: Cek-In / Status Kereta2. Detail Komponen Form "Pesan Tiket"Di dalam Tab 1, buat struktur input grid yang rapi:Asal Stasiun & Tujuan Stasiun: Dua input text/dropdown bersebelahan. Di tengahnya terdapat tombol ikon Swap ($\rightleftarrows$) untuk menukar rute asal dan tujuan.Tanggal Keberangkatan: Input date picker standar.Jumlah Penumpang: Input angka dengan tombol + dan - (Maksimal 4 penumpang).Tombol CTA: Tombol lebar penuh di bagian bawah form bertuliskan "Cari Kereta" dengan warna oranye terang.3. Bagian Bawah & Kanan (Rekomendasi & Konten)Daftar Rute Teraktif (Bawah): Grid system berisi chip atau kartu kecil untuk rute populer (misal: Banyuwangi - Jember, Surabaya - Malang). Jika diklik, otomatis mengisi form Asal & Tujuan di atas.Rekomendasi Terbaik (Kanan): Kartu kereta spesifik (misal: "Logawa"). Jika statusnya "Tersedia", tampilkan harga dan tombol oranye "Pesan Sekarang". Jika statusnya "Dibatalkan", tombol di-disable dan ubah warnanya menjadi abu-abu.4. State Management & Fungsionalitas InteraktifGunakan React Context API untuk mengelola state pemesanan. Buat sebuah BookingContext (mirip seperti logika shopping cart) yang bertugas menyimpan data sementara: stasiunAsal, stasiunTujuan, tanggal, dan penumpang. Hal ini agar data bisa dengan mudah dilempar ke halaman /checkout nanti.Buat state lokal untuk menangani animasi pertukaran tab antara "Pesan Tiket" dan "Cek-In".Berikan validasi disabled pada tombol "Cari Kereta" jika kolom Asal dan Tujuan masih kosong.5. Kebutuhan KodeTolong berikan kode lengkapnya dengan memecahnya menjadi komponen-komponen yang modular (misal: Navbar.tsx, BookingForm.tsx, RecommendationCard.tsx, dan BookingContext.tsx). Gunakan sintaks Next.js (App Router/Pages Router sesuaikan dengan best practice) dan Tailwind CSS untuk styling. Jangan lupa sertakan data mockup statis berupa array of objects untuk menampilkan daftar kereta populer.
